# DJ Grab

**Less prep, more mixing.** DJ Grab turns any song into a ready-to-play track with clean tags, matched volume, custom intros and cue points. It works with any DJ software, on Mac and Windows.

## What it does

- **Search or paste a link.** Type a song name (spelling doesn't have to be perfect) or drop a link, and DJ Grab finds the right version, not the live, cover or lyric-video upload.
- **Clean files.** Correct title, artist and real album art. Silence at the start is trimmed.
- **Matched volume.** Every track comes out at the same loudness without squashing or clipping.
- **Quality check.** Low-bitrate or muffled sources are flagged before they reach your library.
- **DJ intro versions.** Songs that start with vocals get a second copy with a mixable beat intro, made the way DJ pools make them.
- **Cue points and beat grids.** Start, Chorus, Breakdown and Outro are set automatically, for Serato, Rekordbox, Traktor and VirtualDJ.
- **Genre folders (optional).** New downloads can be sorted into Simple or Detailed genre folders.
- **Automatic updates.**

## Install (Mac)

1. Download DJ Grab (coming soon) and unzip it.
2. Drag **DJ Grab** into Applications.
3. The first time, right-click DJ Grab and choose **Open**, then **Open** again. macOS asks this once for apps from outside the App Store.
4. A setup window asks for your DJ software, music folder and a few preferences. DJ Grab installs the tools it needs on first launch.

Windows version coming soon.

## Using your cue points

| Software | How |
|---|---|
| Serato | Nothing to do. Cues are saved inside each song file. |
| Rekordbox | Preferences ▸ Advanced ▸ Database ▸ rekordbox xml: choose `DJ Grab cues/DJ Grab (rekordbox).xml` in your music folder, then open the DJ Grab playlist. |
| Traktor | File ▸ Import Collection, choose `DJ Grab cues/DJ Grab (Traktor).nml`. |
| VirtualDJ | Nothing to do. Cues are added whenever VirtualDJ is closed. |

## Please use responsibly

Only download music you have the right to use. DJ Grab doesn't work with Spotify, Apple Music or other paid streaming services.
